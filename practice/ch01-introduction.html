1 Overview and Conceptual Framework

A time series is a sequence of observations \(Y_1, Y_2, \dots, Y_n\) recorded sequentially through time. Unlike classical cross-sectional statistics where observations are assumed to be independent and identically distributed (\(i.i.d.\)), the defining feature of time series is temporal dependence: consecutive or nearby observations are frequently correlated with one another.

1.1 Objectives of Time Series Analysis

According to Cryer and Chan (Chapter 1), the objectives are twofold:

  1. Descriptive & Mechanistic Understanding: To model and understand the underlying stochastic mechanism that generated the observed sequence.
  2. Forecasting: To predict future values \(Y_{n+h}\) based on the series history \(\{Y_1, \dots, Y_n\}\) and other explanatory covariates.

1.2 The Box-Jenkins Model-Building Strategy

Cryer & Chan emphasize the iterative three-stage modeling cycle proposed by Box and Jenkins (1976):

       ┌───────────────────────────────┐
       │   1. Model Specification      │ <─────────┐
       │   (Tentative Identification)  │           │
       └──────────────┬────────────────┘           │ (Revise if
                      │                            │  inadequate)
                      ▼                            │
       ┌───────────────────────────────┐           │
       │   2. Model Fitting            │           │
       │   (Parameter Estimation)      │           │
       └──────────────┬────────────────┘           │
                      │                            │
                      ▼                            │
       ┌───────────────────────────────┐           │
       │   3. Model Diagnostics        │ ──────────┘
       │   (Residual Checking & Tests) │
       └──────────────┬────────────────┘
                      │ (Adequate model)
                      ▼
       ┌───────────────────────────────┐
       │   Forecasting & Application   │
       └───────────────────────────────┘
  1. Model Specification (Identification): Using visual time plots, sample autocorrelations, and domain knowledge to tentatively select candidate model classes (e.g., AR, MA, ARMA, ARIMA).
    • Principle of Parsimony: The chosen model should contain the smallest number of parameters that adequately describes the data (“Everything should be made as simple as possible, but not simpler” — Albert Einstein).
  2. Model Fitting (Estimation): Estimating unknown parameters using maximum likelihood or least squares.
  3. Model Diagnostics: Examining model residuals to verify whether assumptions hold (e.g., checking that residuals resemble uncorrelated white noise).

3 Textbook Case Studies (Section 1.1)

Chapter 1 introduces five historical and industrial time series demonstrating distinct statistical properties:

3.1 Case 1: Annual Rainfall in Los Angeles (larain)

The larain dataset records annual precipitation (in inches) in Los Angeles over more than 100 years (1878–1992).

Code 
data(larain)

plot(
  larain,
  ylab = "Inches",
  xlab = "Year",
  type = "o",
  pch = 16,
  col = primary_col,
  main = "Annual Rainfall in Los Angeles"
)
grid(col = grid_col)

To examine whether consecutive years are statistically dependent, we construct the lag-1 scatterplot (\(Y_t\) versus \(Y_{t-1}\)) using zlag().

Code 
plot(
  y = larain,
  x = zlag(larain),
  ylab = "Current Year Rainfall (inches)",
  xlab = "Previous Year Rainfall (inches)",
  pch = 19,
  col = point_col,
  main = "LA Rainfall vs. Previous Year"
)
grid(col = grid_col)
abline(h = mean(larain), v = mean(larain), lty = 2, col = "gray50")

# Compute lag-1 sample autocorrelation
r1_larain <- cor(larain[-1], zlag(larain)[-1])

Interpretation: The scatterplot displays a circular, unorganized cloud of points with an empirical lag-1 correlation of \(r_1 \approx -0.033\). Extremely wet years (such as 1883 with 40 inches) can be followed by average or dry years. Past rainfall provides virtually no linear predictive power for next year’s rainfall; this series behaves like independent white noise.

3.2 Case 2: Industrial Chemical Process (color)

The color dataset tracks color intensity across 35 consecutive batches in a chemical manufacturing process.

Code 
plot(

  x = zlag(color),

4.3 Exercise 1.3: Simulated Gaussian Random Process

Simulate a completely random process of length 48 with independent, normal values. Plot the time series plot. Does it look “random”? Repeat this exercise several times with a new simulation each time.

We simulate 4 realizations of length \(n = 48\) with \(e_t \sim i.i.d. \, N(0, 1)\) using explicit seeds:

Code 
par(mfrow = c(2, 2), mar = c(3.5, 3.5, 2.5, 1))

seeds <- c(101, 102, 103, 104)
for (i in seq_along(seeds)) {
  set.seed(seeds[i])
  wn_norm <- ts(rnorm(48))
  
  plot(
    wn_norm,
    type = "o",
    pch = 16,
    col = primary_col,
    ylab = "Value",
    xlab = "Time",
    main = paste("Normal Run", i, "(Seed:", seeds[i], ")")
  )
  abline(h = 0, lty = 2, col = "red")
  grid(col = grid_col)
}

par(mfrow = c(1, 1))

Discussion: Although the underlying process is completely independent, individual finite sample realizations often show localized “runs” or pseudo-clusters (e.g. 3 consecutive values above 0). The human eye often tends to identify false patterns in purely random series.

4.4 Exercise 1.4: Simulated Chi-Square Random Process

Simulate a completely random process of length 48 with independent, chi-square distributed values with 2 degrees of freedom. Display the time series plot. Does it look “random” and nonnormal? Repeat several times.

A \(\chi^2(2)\) distribution has mean \(\mu = k = 2\), variance \(\sigma^2 = 2k = 4\), and is positively skewed (\(\text{Skewness} = \sqrt{8/k} = 2\)).

Code 
par(mfrow = c(2, 2), mar = c(3.5, 3.5, 2.5, 1))

seeds_chisq <- c(201, 202, 203, 204)
for (i in seq_along(seeds_chisq)) {
  set.seed(seeds_chisq[i])
  wn_chisq <- ts(rchisq(48, df = 2))
  
  plot(
    wn_chisq,
    type = "o",
    pch = 16,
    col = accent_col,
    ylab = "Value",
    xlab = "Time",
    ylim = c(0, max(wn_chisq) + 1),
    main = paste("Chi-Square (df=2) Run", i)
  )
  abline(h = 2, lty = 2, col = "black")
  grid(col = grid_col)
}

par(mfrow = c(1, 1))

Discussion: The plots are visibly non-normal: values are bounded below by 0 with frequent sharp upward spikes. However, they remain independent over time; high spikes do not predict subsequent spikes.

4.5 Exercise 1.5: Simulated Heavy-Tailed Student’s t Process

Simulate a completely random process of length 48 with independent, t-distributed values each with 5 degrees of freedom. Construct the time series plot. Does it look “random” and nonnormal? Repeat several times.

The \(t(5)\) distribution is symmetric with mean 0 and variance \(\frac{\nu}{\nu - 2} = \frac{5}{3} \approx 1.67\), but possesses heavy tails (leptokurtic).

Code 
par(mfrow = c(2, 2), mar = c(3.5, 3.5, 2.5, 1))

seeds_t <- c(301, 302, 303, 304)
for (i in seq_along(seeds_t)) {
  set.seed(seeds_t[i])
  wn_t <- ts(rt(48, df = 5))
  
  plot(
    wn_t,
    type = "o",
    pch = 16,
    col = point_col,
    ylab = "Value",
    xlab = "Time",
    main = paste("Student's t (df=5) Run", i)
  )
  abline(h = 0, lty = 2, col = "red")
  grid(col = grid_col)
}

par(mfrow = c(1, 1))

Discussion: The series looks symmetric around 0, but exhibits occasional extreme isolated spikes (heavy tails). Crucially, the extreme observations are single events that immediately return toward the mean, demonstrating temporal independence.

5 Chapter 1 Synthesis: Key Takeaways

Dataset Sampling Frequency Dominant Pattern Temporal Dependence
larain Annual White noise Uncorrelated (\(r_1 \approx 0\))
color Batch Short memory / Persistence Moderate positive (\(r_1 \approx 0.6\))
hare Annual Multi-year population cycles Strong positive (\(r_1 \approx 0.7\))
tempdub Monthly Deterministic annual seasonality High periodic dependence (\(s = 12\))

5.1 Fundamental Theoretical Insight

Never confuse the marginal distribution (shape across a histogram, e.g. Normal, Chi-square, Student’s \(t\)) with temporal dependence (correlation across time). A series can be highly non-normal yet completely independent, or perfectly normal yet strongly autocorrelated.

### Exercise 1.3: Simulated Gaussian Random Process

> *Simulate a completely random process of length 48 with independent, normal values. Plot the time series plot. Does it look "random"? Repeat this exercise several times with a new simulation each time.*

We simulate 4 realizations of length $n = 48$ with $e_t \sim i.i.d. \, N(0, 1)$ using explicit seeds:

```{r}
#| label: fig-ex-1-3
#| fig-cap: "Exercise 1.3: Four independent realizations of standard Gaussian white noise (n = 48)."
#| fig-height: 6
par(mfrow = c(2, 2), mar = c(3.5, 3.5, 2.5, 1))

seeds <- c(101, 102, 103, 104)
for (i in seq_along(seeds)) {
  set.seed(seeds[i])
  wn_norm <- ts(rnorm(48))
  
  plot(
    wn_norm,
    type = "o",
    pch = 16,
    col = primary_col,
    ylab = "Value",
    xlab = "Time",
    main = paste("Normal Run", i, "(Seed:", seeds[i], ")")
  )
  abline(h = 0, lty = 2, col = "red")
  grid(col = grid_col)
}

par(mfrow = c(1, 1))
```

**Discussion:**
Although the underlying process is completely independent, individual finite sample realizations often show localized "runs" or pseudo-clusters (e.g. 3 consecutive values above 0). The human eye often tends to identify false patterns in purely random series.

### Exercise 1.4: Simulated Chi-Square Random Process

> *Simulate a completely random process of length 48 with independent, chi-square distributed values with 2 degrees of freedom. Display the time series plot. Does it look "random" and nonnormal? Repeat several times.*

A $\chi^2(2)$ distribution has mean $\mu = k = 2$, variance $\sigma^2 = 2k = 4$, and is positively skewed ($\text{Skewness} = \sqrt{8/k} = 2$).

```{r}
#| label: fig-ex-1-4
#| fig-cap: "Exercise 1.4: Four realizations of independent Chi-Square (df = 2) white noise (n = 48)."
#| fig-height: 6
par(mfrow = c(2, 2), mar = c(3.5, 3.5, 2.5, 1))

seeds_chisq <- c(201, 202, 203, 204)
for (i in seq_along(seeds_chisq)) {
  set.seed(seeds_chisq[i])
  wn_chisq <- ts(rchisq(48, df = 2))
  
  plot(
    wn_chisq,
    type = "o",
    pch = 16,
    col = accent_col,
    ylab = "Value",
    xlab = "Time",
    ylim = c(0, max(wn_chisq) + 1),
    main = paste("Chi-Square (df=2) Run", i)
  )
  abline(h = 2, lty = 2, col = "black")
  grid(col = grid_col)
}

par(mfrow = c(1, 1))
```

**Discussion:**
The plots are visibly **non-normal**: values are bounded below by 0 with frequent sharp upward spikes. However, they remain **independent over time**; high spikes do not predict subsequent spikes.

### Exercise 1.5: Simulated Heavy-Tailed Student's t Process

> *Simulate a completely random process of length 48 with independent, t-distributed values each with 5 degrees of freedom. Construct the time series plot. Does it look "random" and nonnormal? Repeat several times.*

The $t(5)$ distribution is symmetric with mean 0 and variance $\frac{\nu}{\nu - 2} = \frac{5}{3} \approx 1.67$, but possesses heavy tails (leptokurtic).

```{r}
#| label: fig-ex-1-5
#| fig-cap: "Exercise 1.5: Four realizations of independent Student's t (df = 5) white noise (n = 48)."
#| fig-height: 6
par(mfrow = c(2, 2), mar = c(3.5, 3.5, 2.5, 1))

seeds_t <- c(301, 302, 303, 304)
for (i in seq_along(seeds_t)) {
  set.seed(seeds_t[i])
  wn_t <- ts(rt(48, df = 5))
  
  plot(
    wn_t,
    type = "o",
    pch = 16,
    col = point_col,
    ylab = "Value",
    xlab = "Time",
    main = paste("Student's t (df=5) Run", i)
  )
  abline(h = 0, lty = 2, col = "red")
  grid(col = grid_col)
}

par(mfrow = c(1, 1))
```

**Discussion:**
The series looks symmetric around 0, but exhibits occasional extreme isolated spikes (heavy tails). Crucially, the extreme observations are single events that immediately return toward the mean, demonstrating temporal independence.

### Exercise 1.6: Dubuque Temperatures with Seasonal Symbols

> *Construct a time series plot with monthly plotting symbols for the Dubuque temperature series as in Exhibit 1.7 on page 6. The data are in the file named `tempdub`.*

```{r}
#| label: fig-ex-1-6
#| fig-cap: "Exercise 1.6: Dubuque monthly temperatures with month character symbols."
data(tempdub)

plot(
  tempdub,
  type = "l",
  col = "gray50",
  ylab = "Average Temperature (°F)",
  xlab = "Year",
  main = "Dubuque Monthly Temperature with Month Symbols"
)
grid(col = grid_col)

# Add monthly letters (J, F, M, A, M, J, J, A, S, O, N, D)
points(
  y = tempdub,
  x = time(tempdub),
  pch = as.vector(season(tempdub)),
  col = primary_col,
  font = 2,
  cex = 0.85
)
```

**Discussion:**
The monthly labels illustrate that the cyclical waveform is strictly synchronized with the calendar year: **J** (January) always forms the trough ($\approx 15^\circ\text{F}$) while **J** (July) always forms the peak ($\approx 75^\circ\text{F}$).

## Chapter 1 Synthesis: Key Takeaways

| Dataset | Sampling Frequency | Dominant Pattern | Temporal Dependence |
| :--- | :--- | :--- | :--- |
| **`larain`** | Annual | White noise | Uncorrelated ($r_1 \approx 0$) |
| **`color`** | Batch | Short memory / Persistence | Moderate positive ($r_1 \approx 0.6$) |
| **`hare`** | Annual | Multi-year population cycles | Strong positive ($r_1 \approx 0.7$) |
| **`tempdub`** | Monthly | Deterministic annual seasonality | High periodic dependence ($s = 12$) |
| **`oilfilters`** | Monthly | Winter surge / Autumn drop | Seasonal demand pattern |

### Fundamental Theoretical Insight
Never confuse the **marginal distribution** (shape across a histogram, e.g. Normal, Chi-square, Student's $t$) with **temporal dependence** (correlation across time). A series can be highly non-normal yet completely independent, or perfectly normal yet strongly autocorrelated.
